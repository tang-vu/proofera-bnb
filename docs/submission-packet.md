## Project Description

ProofEra is a risk-aware marketplace for autonomous DeFi agents on BNB Smart Chain. Users start
with a financial job—Pancake concentrated liquidity, bounded grid trading, sustainable yield, or
Venus health-factor protection—and inspect category-specific sources, freshness, downside, costs
and unknowns before authority moves. Four public read-only analyzers have finalized BSC-testnet
ERC-8004 identities 1825 through 1828; registration is presented as identity publication, never as
performance proof.

ProofEra's control model fixes chain, target, selector, token, spend cap and expiry, keeps grant and
revoke with the owner, and refuses blind retries after ambiguous writes. A retained Altana chain-97
lifecycle joins successful grant, scoped session action, revoke and final authority absence. Three
TermiX agent/manual pairs attach actual bounded outputs and report time, explicit cost and output
quality. Both lanes scored 100/100 and timing was mixed, so no universal agent advantage is claimed.

For PancakeSwap, a controlled testnet LP has finalized approval/mint receipts and dual-provider
post-state. Its 9,104-second outcome observed unchanged price/liquidity and zero fees; ProofEra
therefore claims no realized Pancake benefit. The Proof Room binds every positive claim and blocker
to retained evidence. Missing evidence stays missing.
