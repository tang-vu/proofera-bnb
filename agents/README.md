# ProofEra reference agents

Reference agents are generated with the exact current BNB Agent Studio CLI and then reviewed before dependencies, wallets, registration, or deployment are introduced. Local `.studio/` state and every keystore remain ignored.

The first workspace is the PancakeSwap LP-range vertical slice. Scaffold presence is not live-agent evidence; an agent becomes live only after durable endpoint, health, BSC identity, execution, and revoke evidence are captured.
