# Demo video evidence

`scripts/capture-public-demo-video.mjs` writes create-only exact-release artifacts beneath
`<source-commit>/<mode>/`.

`rehearsal` output is a silent technical recording and never closes the demo gate. `final` output is
allowed only after production, registration, Altana and TermiX are verified. Pancake must either be
verified or retain the exact controlled negative-outcome boundary (receipt, before/after metrics,
manual baseline and explicit no-benefit/no-agent-advantage claim). Final mode requires committed
narration, one audio stream, full media decoding, and a 240–330 second duration.

The retained `ad03498` final artifact has six scenes and a 297.080-second narrated MP4. A separate
process copied the media to a temporary boundary, rehashed it, completed another full audio/video
decode and rechecked all six public scene assertions. That automated check is not a human narration
quality attestation, a separate physical-device review, or a hackathon submission receipt.
