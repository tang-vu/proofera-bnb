# Demo video evidence

`scripts/capture-public-demo-video.mjs` writes create-only exact-release artifacts beneath
`<source-commit>/<mode>/`.

`rehearsal` output is a silent technical recording and never closes the demo gate. `final` output is
allowed only after production, registration, Altana and TermiX are verified. Pancake must either be
verified or retain the exact controlled negative-outcome boundary (receipt, before/after metrics,
manual baseline and explicit no-benefit/no-agent-advantage claim). Final mode requires committed
narration, one audio stream, full media decoding, and a 240–330 second duration.

The retained `89a99e8` final artifact has six scenes and a 325.014-second MiMo-narrated MP4. A
separate process copied the media to a temporary boundary, rehashed it, completed another full
audio/video decode and rechecked all six public scene assertions. YouTube video `ron927GeVXI` has a
separate timestamped anonymous publication observation in
`evidence/submission/youtube-publication-2026-09-05.json`. Neither automated check is a human
narration-quality attestation, a separate physical-device review, or a hackathon submission receipt.
